Phone & HTTPS setup

Use the same Wi-Fi. Start the server with HOST=0.0.0.0 to make LAN addresses available in the selector. Choose your Wi-Fi address if you see several.

The Copy button needs HTTPS on phones. Put this server behind a trusted HTTPS reverse proxy, forward WebSocket upgrades for /signal, and set PUBLIC_URL to its HTTPS address. Until then, select received text and copy it manually.

iOS may pause this page in the background. Return here, wait for Connected, then send. Leaving ends the room and forgets this pairing.
